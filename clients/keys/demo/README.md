# Published on purpose

These are two of the three shares of a throwaway account,
`yml1usn8yrkkjeprqec8rwfmatxqt95ak0lq4s4s6d`, which holds nothing and never
will. They are here so the page beside them can run the real protocol in a
browser instead of describing it.

Two shares is a signing quorum. Anybody who reads these files can sign for that
account, and that is fine and intended: there is nothing to sign for. It is also
the clearest possible demonstration of the rule — two shares are enough, which
is exactly why a real account never keeps two in one place.

The recovery share is deliberately not here. Not because it would be more
dangerous, but because publishing all three would invite somebody to describe
this as "the whole key", and there is no such object.

No real account's share is in this repository, and none ever should be.
